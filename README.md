# Tau Gamma Phi Community Portal

A proposed frontend community portal for the **Tau Gamma Phi – Concepcion Chapter**.

## Project Description

The Tau Gamma Phi Community Portal aims to provide a centralized and reliable platform for sharing organizational information, upcoming events, community programs, announcements, and member attendance.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
